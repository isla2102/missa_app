# 로마 미사 경본 미사 통상문 · 기준 원본 검토

확인일: 2026-10-24. 사용자 제공 PDF를 원문·지시문·악보 배치의 우선 대조 기준으로 등록했다. 원본 파일과 앱 본문은 변경하지 않았다.

## 확인 결과
- 238쪽, 전 페이지 이미지. 추출 가능한 텍스트 층은 없다.
- 니케아 신경·사도 신경, 감사 기도 제1–4양식이 포함된다. 이전 두 DOCX는 펼쳐진 양식과 복사 범위가 달랐다.
- 감사송, 장엄 강복, 감사 기도 노래, 봉사자 한 사람만 참여하는 미사, 라틴어 통상문, 화해·기원 미사 감사 기도 등으로 범위가 더 넓다.
- 검은 본문과 자홍 계열 지시문·역할 표기, 악보를 구분한다. 앱에서는 이 의미 구분을 참고하되 확정한 와인색 디자인을 임의 변경하지 않는다.
- PDF15쪽(책549쪽)은 신경 전체 악보를 『로마 미사 성가집』에서 참조하도록 명시한다. 이 파일에 모든 악보 전문이 있다고 보아서는 안 된다.
- PDF99쪽의 주님의 기도는 파일 밖 부록 악보도 참조한다. 내부 교차 참조가 모두 이 파일에 포함되지는 않는다.
- PDF 생성 일시는 판본·출판일의 증거가 아니다. 판본은 미확인이다.

## 자료 역할
1. 사용자 제공 PDF: 본문·전례 지시·악보의 시각 원본 우선 대조.
2. 주교회의 DOCX: 텍스트 입력 보조. PDF와 항별로 확인한 뒤 사용.
3. 서울대교구 DOCX: 해설과 추가 캡처 범위 확인. 전례 지시문과 사이트 해설을 분리.
4. 로컬 OCR: 검색 보조만 사용. 오인식이 있어 앱의 검증된 본문으로 자동 반영하지 않는다.
