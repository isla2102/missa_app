- 제목 선언: 20px, #d90099, Nanum Gothic.
- 본문 전용 선언: 18px, #444, 궁서.
- 보조 안내 선언: 14px, #777, Nanum Gothic.
- 자세/일부 강조 선언: 14px, #ec00a6. 다른 지시문에는 #ff0000 선언도 존재.
- 이는 CSS 선언 분석이다. 실제 계산 스타일은 선택자·우선순위·설치 글꼴·사이트 글자 크기 조절에 따라 달라질 수 있다.
- 원문 CSS 전체를 앱에 넣거나, 확정한 와인색·본문18px/1.6 디자인을 변경하지 않았다.
- 전문 복제 대신 공식 사이트 열람 링크와 25단어 이내의 짧은 서식 예시를 제공한다.

## 날짜 주소 검증
[주교회의 2026-10-14 원문](https://missa.cbck.or.kr/DailyMissa/20261014)

- URL 형식: https://missa.cbck.or.kr/DailyMissa/YYYYMMDD
- 별도 게시물 번호 없이 해당 날짜 화면이 열리는 사례 확인.
- 샘플은 본기도·독서·화답송·복음·예물 기도·영성체 관련 항목 등을 HTML로 제공한다.
- 이 사례는 스크롤 동작 없이도 구조를 읽을 수 있다. 모든 날짜의 동일한 구조·미래 자료 존재·공식 API는 검증하지 않았다.
- 주교회의 페이지가 1차 발행 기관의 조회 경로다. 수원교구는 제공된 월간 자료의 보조 입수 경로로 구분하는 방안을 추천한다.
- 수원교구가 독자 정리한 파일인지, 원문을 그대로 배포한 것인지, 계속 게시할지는 이번 확인으로 단정하지 않는다.

- 기술적 조회 가능성과 자동 수집·앱 저장 허용은 별개다.
- 일괄 크롤러·백그라운드 다운로드·정기 수집은 만들거나 실행하지 않았다.

- 이번 자료함은 날짜별 URL을 생성하여 사용자가 원문을 여는 방식. 숨은 프록시·iframe 자동 수입은 없다.
- robots.txt 404를 자동 수집 허가로 해석하지 않는다.
