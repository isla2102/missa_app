# 7단계 콘텐츠 연결 준비

이번 작업은 자료실 정리와 조사이다. 새 기도문 전문을 앱 데이터에 자동 수입하지 않았다.

- 월간 고유기도문 → 본기도 / 예물 기도 / 영성체 후 기도 등 실제 수록 범위부터 판독.
- 성가표 → 날짜별 추천 번호. 본당·회차 편성은 사용자 선택으로 유지.
- ENC → 성가 번호별 원본 후보. 현재 렌더러가 직접 읽을 수 있는 포맷으로 확인된 것은 아님.
- 교회음악 해설 → 예비신자 도움말 후보. 조사 문장을 그대로 확정 앱 안내로 승격하지 않음.

## 다음 실행 순서
1. 선택 상태·보기 설정·성가 편성·중앙 안내창을 7단계 검수 화면에서 확인.
2. 사용자 제공 HWP 3개월의 실제 항목과 날짜 구조 판독. 누락·반복·선택 기도문을 구별.
3. 하루 분량만 연결해 원본과 대조하는 샘플 준비. 날짜·회차·새로고침 복원 회귀 포함.
4. 사용자 확인 후 연결 범위를 확대. 8단계는 7단계 승인 후 진행.

판독 대기와 시각 승인 대기를 별도 상태로 관리한다. 날짜별 전례문을 추측 생성하지 않는다.
