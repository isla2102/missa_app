# 미사 순서·의미 — 강의용 흐름 지도

일반적인 로마 전례 미사를 설명하는 요약이다. 모든 항목이 매일 등장하는 것은 아니다.
공식 대조: [로마 미사 경본 총지침](https://www.vatican.va/roman_curia/congregations/ccdds/documents/rc_con_ccdds_doc_20030317_ordinamento-messale_en.html) 제2장 46–90항. 교황청 게재 영문에는 미국 지역 적응 조항도 있으므로 한국의 세부 적용은 한국어판으로 확인한다.

## 시작 예식
- **입당** → 공동체를 모으고 전례를 시작함. (총지침 47–48항)
- **성호경·인사** → 주님의 현존과 모임을 확인함. (총지침 50항)
- **참회 예식·자비송** → 자비를 청함. (총지침 51–52항)
- **대영광송** → 하느님을 찬미함. (총지침 53항)
- **본기도** → 공동체의 기도를 모음. (총지침 54항)
## 말씀 전례
- **제1독서·화답송·제2독서** → 말씀을 듣고 시편으로 응답함. (총지침 55–61항)
- **부속가·복음 환호송** → 해당 전례의 노래와 복음 환호. (총지침 62–64항)
- **복음·강론** → 복음 선포와 삶의 해설. (총지침 60,65–66항)
- **신앙 고백** → 믿음으로 응답함. (총지침 67–68항)
- **보편 지향 기도** → 교회와 세상을 위해 청원함. (총지침 69–71항)
## 성찬 전례
- **예물 준비·예물 기도** → 성찬을 준비함. (총지침 72–77항)
- **감사송·거룩하시도다** → 감사와 공동 환호. (총지침 79a–b항)
- **감사 기도·신앙의 신비·아멘** → 그리스도의 파스카를 기념함. (총지침 78–79항)
- **주님의 기도·후속 기도·환호** → 영성체를 준비하며 청원함. (총지침 81항)
- **평화 예식·빵 나눔·하느님의 어린양** → 평화와 한 빵의 일치. (총지침 82–83항)
- **영성체·침묵·영성체 후 기도** → 성체를 모시고 감사함. (총지침 84–89항)
## 마침 예식
- **공지·강복·파견** → 일상으로 보내심. (총지침 90항)

## 생략·선택 구분
- 대영광송·신경·제2독서·부속가는 전례일에 따라 확인한다. 대림·사순의 주일에는 대영광송이 없지만 대축일·축일 등과 혼동하지 않는다.
- 참회 제3양식의 자비송을 별도 반복하지 않는다. 성수 예식 대체도 구별한다.
- 파견 노래와 전례 자체의 파견은 서로 다른 항목이다.
- 본기도·예물 기도·영성체 후 기도는 날짜별 고유문 연결 지점이다. 고유기도문 파일을 독서·복음 전체 자료로 단정하지 않는다.
