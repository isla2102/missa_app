## 범위·검증 구분
- 카테고리 목록 83개 확보. 나머지 67개 글은 목록만 정리했고 전문을 읽었다고 표시하지 않았다.
- 선별 16개는 게시글 본문 기준. 첨부 논문 PDF와 연결 전자책은 미판독.
- 블로그 게시 순서와 저자 책 차례의 번호는 다를 수 있어 글 ID를 식별자로 사용.
- 역사적 추정·저자 의견은 현행 전례 규범으로 확정하지 않는다.
- 교황청 총지침 영문은 지역 적응이 포함된 판본. 한국어 세부 규정은 국내 공식판 재확인 대상.
- 조사용 임시 읽기 텍스트는 scratch에만 보관. 배포용 요약 파일에는 전문·악보·영상 복제본을 넣지 않았다.
