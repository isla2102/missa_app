# 강의자료 구성안 — 미사 흐름으로 배우는 교회음악

상태: 조사 기반 구성 초안. 슬라이드·강의 교안 완성본은 아님.

## 추천: 60분 입문 강의
1. 5분 · 큰 흐름 4개: 시작 → 말씀 → 성찬 → 마침. 02 흐름 지도를 한 장으로 사용.
2. 8분 · 고유문 / 통상문: 날짜별 파일과 고정 본문을 비교. 글 5를 읽고 용어 분류 연습.
3. 10분 · 듣고 응답하기: 화답송의 선창/회중 역할을 분담. 글 1·2, 공식 총지침 61항 대조.
4. 12분 · 함께 바치는 찬미와 믿음: 대영광송·신경. 글 14·15의 배경을 읽고 본문과 해설을 구분.
5. 15분 · 성찬과 노래: 예물 준비부터 영성체까지. 글 33·65와 실제 성가표를 사용해 곡의 위치 설명.
6. 10분 · 실습과 질문: 같은 날짜의 고유문·수정 성가표·선택 악보를 하나의 흐름에 배치.

## 후속 강의 묶음
- 전례력과 선곡: 글 4·부록 5. 날짜와 축일의 연결.
- 특별 전례: 글 16·37·51. 부속가·성수 예식·참회 양식.
- 성가대 직무: 부록 3·4. 국내 지침과 첨부 논문 판독 후 확장.

## 매 슬라이드의 공통 틀
- 지금 어느 순서인가 → 어떤 의미인가 → 누가 무엇을 하는가 → 음악은 어떤 역할인가.
- 원문 주소·공식 문헌 항 번호·조회일을 발표자 노트에 기록.
- 해설은 새 문장으로 쓰고 원문·악보 이미지·영상은 이용 범위 확인 후 선택.
- 개인 음악사 해석은 ‘저자 해설’로 표시. 전례 규범·교리 설명과 섞지 않기.

## 강의 제작 전 확인할 것
- 대상: 예비신자 입문 / 일반 신자 / 성가대 봉사자 중 선택.
- 실제 강의 시간과 실습 여부 결정.
- 한국어 공식 지침의 세부 규정 확인 및 본당 전례 담당자 검토.
- 첨부 논문과 전자책은 이번 조사에서 전문 미판독.
