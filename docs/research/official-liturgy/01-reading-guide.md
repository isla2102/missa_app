# 공식 문헌 읽기 길잡이

## 추천 순서
1. SC: 전례의 목적과 참여.
2. GIRM·ORDO: 구조·역할·실제 순서.
3. OLM: 독서·시편·복음.
4. K-MUSIC·MS: 한국의 성음악 적용과 배경.
5. K-CALENDAR·DAILY: 날짜·선택 고유문.

## 문헌별 출처와 판독 범위

### SC · 거룩한 전례에 관한 헌장 — Sacrosanctum Concilium
- 기관: 제2차 바티칸 공의회
- 판본: 1963-12-04
- 유형: 공의회 헌장 / 영어
- [공식 원문·열람 페이지](https://www.vatican.va/archive/hist_councils/ii_vatican_council/documents/vat-ii_const_19631204_sacrosanctum-concilium_en.html)
- 확인: 7,10–14항 및 제6장 성음악의 112항을 중심으로 선별 확인
- 한계: 전체 공의회 문헌·후속 개정 전부를 검토한 것은 아님

### GIRM · 로마 미사 경본 총지침 — General Instruction of the Roman Missal
- 기관: 교황청 경신성사성 / 교황청 게재
- 판본: 교황청 영문 게재본; 미국 지역 적응 포함
- 유형: 미사 경본 총지침 / 영어
- [공식 원문·열람 페이지](https://www.vatican.va/roman_curia/congregations/ccdds/documents/rc_con_ccdds_doc_20030317_ordinamento-messale_en.html)
- 확인: 34–45,46–90,91–105항 중 미사 구조·침묵·역할 관련 내용 선별 확인
- 한계: 미국 적응인 자세·선곡 목록 등을 한국에 그대로 적용하지 않음

### K-GIRM · 로마 미사 경본 총지침·미사 독서 목록 지침 한국어판 발행 안내
- 기관: 한국천주교주교회의 전례위원회
- 판본: 2018-05-15 발행 안내
- 유형: 공식 서지·목차 안내 / 한국어
- [공식 원문·열람 페이지](https://cbck.or.kr/documents/other/402681)
- 확인: 서지·국내 사용 배경·차례 확인
- 한계: 이 URL은 총지침 전문이 아닌 도서 소개; 한국어 총지침 전체 판독 완료로 표시하지 않음

### OLM · 미사 독서 목록 지침 — Ordo Lectionum Missae, Praenotanda
- 기관: 교황청 문헌 / 한국천주교주교회의 한국어 게재
- 판본: 1981-01-21
- 유형: 독서 목록 지침 / 한국어
- [공식 원문·열람 페이지](https://cbck.or.kr/documents/other/402071)
- 확인: 11–14,19–23,46–47,64–69,78항 중심 선별 확인
- 한계: 전문 열람 가능. 모든 날짜의 독서 배정표를 앱에 검증·수입한 것은 아님

### MS · 거룩한 전례의 음악에 관한 훈령 — Musicam sacram
- 기관: 교황청 예부성성
- 판본: 1967-03-05
- 유형: 성음악 훈령 / 영어
- [공식 원문·열람 페이지](https://www.vatican.va/archive/hist_councils/ii_vatican_council/documents/vat-ii_instr_19670305_musicam-sacram_en.html)
- 확인: 15–19,23–24,26–36항 중심 선별 확인
- 한계: 당시 전례 개혁의 문맥과 이후 미사 경본·한국 지침을 함께 읽음

### K-MUSIC · 한국 천주교 성음악 지침 — 개정판
- 기관: 주교회의 전례위원회 / 한국천주교중앙협의회
- 판본: 제2판 1쇄 2017-12-01 / 제2판 2쇄 2018-03-23
- 유형: 한국 성음악 지침 / 한국어
- [공식 원문·열람 페이지](https://ebook.cbck.or.kr/gallery/view.asp?seq=214687)
- 확인: 표제·판권·목차와 인쇄쪽 26,27,28,31,35,38,41 선별 직접 판독
- 한계: 이미지 전자책 52면. 연속 전쪽 판독 아님; 읽은 면에 이어지는 문장은 미확인으로 구분

### K-CALENDAR · 전례력의 이해 — 전례일의 등급·순위와 한국의 이동 경축
- 기관: 한국천주교주교회의 매일미사
- 판본: 2026-10-23 열람
- 유형: 공식 해설·규범 인용 / 한국어
- [공식 원문·열람 페이지](https://missa.cbck.or.kr/LiturgyInfo)
- 확인: 등급·순위표, 겹치는 전례일, 대축일 이동 관련 항목
- 한계: 전례주년과 전례력 일반 규범 전문을 별도 확보한 것은 아님; 연도별 고유 전례력 대조 필요

### ORDO · 미사 통상문 — 한국어 로마 미사 경본
- 기관: 한국천주교주교회의 / 한국천주교중앙협의회
- 판본: 2017년 대림부터 사용하는 한국어 제3판 계열
- 유형: 공식 예식 본문·지시문 / 한국어
- [공식 원문·열람 페이지](https://missale.cbck.or.kr/OrdoMissae)
- 확인: 시작 예식의 인사 대안·성수 예식 대체·참회와 자비송 연결 지시 확인
- 한계: 전문은 앱에 새로 복제하지 않음; 모든 기도 양식의 세부 교감 완료 아님

### DAILY · 매일미사 일러두기
- 기관: 한국천주교주교회의 매일미사
- 판본: 2026-10-23 열람
- 유형: 공식 수록·선택 기준 안내 / 한국어
- [공식 원문·열람 페이지](https://missa.cbck.or.kr/DailyMissaInfo)
- 확인: 고유 기도문 반복·선택, 독서 배정, 보편 지향 기도 항목 확인
- 한계: 월간 HWP의 실제 내용 판독과 날짜별 원문 검증을 대신하지 않음
