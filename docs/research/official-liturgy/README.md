├─ sources.json / .csv         공식 문헌 9건·판본·확인 범위

- 기본 원칙: 공식 문헌의 요약 / 연구자의 해석 / 앱 제안을 구별.
- 전문 사본 대신 짧은 요약과 공식 원문·항 번호를 연결.
- 국내 규정은 한국어 공식판·한국 주교회의·교구의 적용을 확인.
- 오래된 문헌이라는 이유만으로 폐기하거나, 모든 조항이 현재 그대로 적용된다고 단정하지 않음.
- 9건 모두 지침 전문은 아님. 도서 소개·공식 해설·통상문을 출처 유형으로 구분.
- 앱 변경·강의 배포 승인·교구 전례 담당자의 검토 완료를 의미하지 않음.
