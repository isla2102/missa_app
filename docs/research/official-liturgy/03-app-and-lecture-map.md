# 앱 검수·강의 제작 연결안

상태: 조사에 따른 제안. 현재 앱의 규칙·디자인·저장 데이터는 변경하지 않았다.

## 앱 검수 항목
- 참회 제3양식 → 자비송 중복이 없는지 확인. 근거: GIRM 52, ORDO.
- 인사 대안 → 선택한 양식과 보조 ‘또는’ 표기 검수. 근거: ORDO.
- 주님의 기도 → 사제/회중 발화 순서 확인. 근거: K-MUSIC 60.
- 화답송 → 선창/회중 후렴 표시 확인. 근거: K-MUSIC 52, OLM.
- 성가 편성 → 노래의 예식 위치와 전례문 역할을 별도 데이터로 관리하는 안 검토. 근거: K-MUSIC 44–48·57·65.
- 날짜 → 주기·등급·이동·본당 고유 전례력은 별도 판정 입력으로 검토. 근거: K-CALENDAR, OLM.
- 안내 → 읽기·듣기·침묵을 방해하지 않는 분량 검토. 근거: SC, GIRM 45.
- 일반/예비신자 모드 → 공식 본문을 새로 쓰는 필터가 아닌 해설 표시 차이 유지.

## 강의 자료 연결
1. 도입: SC로 참여의 목적 설명. 토론 질문 ‘노래하지 않을 때도 참여하는가?’
2. 흐름: GIRM·ORDO를 기준으로 4부분 지도. 각 파트의 행동과 발화자를 함께 표시.
3. 듣고 응답: OLM·K-MUSIC으로 시편 후렴 실습. 실제 본문은 승인된 자료를 선택.
4. 성찬과 음악: K-MUSIC의 관련 항을 확인하고 곡의 위치를 연결하는 실습.
5. 전례력: K-CALENDAR로 같은 날짜에 겹치는 기념을 사례로 검토.
6. 마무리: 블로그 해설은 확장 읽기, 공식 문헌은 근거로 나란히 표시.

슬라이드마다 출처 ID·항 번호·판본·확인일을 발표자 노트에 기록한다. 기존 ../church-music/03-lecture-outline.md를 보충하는 구성안이다.
