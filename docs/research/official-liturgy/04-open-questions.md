# 추가 확인 사항과 판본 구분

## 이번 확인으로 좁혀진 것
- K-MUSIC 공식 전자책의 판권: 제2판1쇄 2017-12-01, 제2판2쇄 2018-03-23. 이미지 면수와 인쇄 쪽수는 2면 차이.
- 기존 블로그 노트에서 미판독으로 표시했던 성음악 전자책은 이번에 관련 면을 선별 판독했다. 블로그 첨부 논문은 여전히 미판독.
- 평화 예식의 노래는 한국 지침61항을 기준으로 대조할 항목이다. 앱의 현재 구현에 위반이 있다고 판정한 것은 아니다.

## 완료로 처리하지 않은 것
- 한국어 총지침 전체 및 국내 적응·후속 공문 전체 확인.
- K-MUSIC의 읽지 않은 면과 관련 항의 다음 면. 52·57항 일부는 다음 면으로 이어짐.
- 전례주년과 전례력 일반 규범 전문의 독립 판본 조사. 이번에는 공식 해설의 인용 조항을 확인.
- 2026·2027 한국 전례력과 해당 본당 고유 전례력 대조.
- 혼인·장례·어린이 미사·성삼일 등 별도 예식서와 특례 전수조사.
- 공식 본문·악보·음원을 앱에 내장하거나 강의로 배포하는 이용 범위 확인.
