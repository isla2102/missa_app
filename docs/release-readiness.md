# 출시 준비 체크리스트와 재개 리마인드

마지막 사용자 결정: 2026-10-24

## 현재 상태
- 개인적으로 사용하는 비영리 테스트·개발 단계.
- 저작권 문의 초안은 보관하고 지금은 발송하지 않는다.
- 문의·승인·정식 배포는 미실행. 사용자 제공 파일의 비교·정리와 개발은 계속한다.

## 프로젝트를 쉬었다가 다시 시작할 때
1. docs/progress.md 첫머리의 이 항목을 읽는다.
2. 정식 출시 준비로 재개하는지 먼저 확인한다. 재개 자체를 출시 승인으로 처리하지 않는다.
3. 출시 준비라면 사용자에게 “보관해 둔 공식 데이터 이용·저작권 문의를 진행할 시점”이라고 리마인드한다.
4. 문의는 사용자가 발송을 지시할 때 진행한다. 자동 발송하지 않는다.

달력 날짜로 예약한 알림은 없다. 프로젝트 재개·출시 준비 시점에 적용하는 작업 절차다.

## 테스트 단계에서 바로 이어갈 일
92일의 시기별 순서·원문 지시문·감사송 적용과 날짜별 최종 통합 검증을 이어간다. 문의를 개발의 반복 확인 질문이나 선행 차단 조건으로 두지 않는다.

## 2026-10-24 사용자 확정 — 자료 입수 경로
- 굿뉴스와 주교회의 두 입수 경로를 모두 선택지로 유지한다. 현재 굿뉴스에서 연결한 자료는 유지한다.
- 출시 준비 단계에서 주교회의를 저작권 이용·데이터 제공 문의의 우선 창구로 삼는다. 담당 기관·개별 자료 권리와 조건은 회신으로 확인한다.
- 주교회의가 제공·허용하는 방식으로 입수할 수 있으면 주교회의를 우선 출처로 전환한다. 현재 허가 또는 전환 완료로 처리하지 않는다.
- 문의 항목: 제공 형식/API/파일, 자동 수집, 캐시·기기 저장·오프라인, 앱 배포, 갱신, 출처 표시.
- 전환 시 날짜·전례명·미사 양식·장절·본문·대안을 대조하고 출처 이력을 보존한다. 굿뉴스 경로도 대조/대체 선택지로 유지한다.
- 현재 문의 발송 없음. 별도 예약 알림 없이 출시 준비·재개 점검 절차에서 리마인드한다.
