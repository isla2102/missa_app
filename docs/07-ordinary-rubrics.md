# 통상문 구조·원문 지시문 연결

2026-10-24 · 7단계 수정 구현, 시각 승인 대기.

## 구조 판정
- 시작 예식 → 말씀 전례 → 성찬 전례 → 마침 예식의 큰 순서는 적절하다.
- 기존 내부 데이터는 사진 판독 문자열에 본문·선택문·앱 해설이 혼재했다. 참회 제2양식은 미연결이고, 두 번째 수록 문자열은 실제 제3양식이었다.
- 원본 자료를 기준으로 양식을 식별하고 지시문 출처를 관리하도록 보완했다. 화면 순서만 맞는 것을 완성된 통상문 데이터 구조로 보지 않는다.

## 반영
- `data/reference-sources/missal-ordinary.json`: 현재 지원 본문·참회 양식ID·지시문 항 번호/PDF쪽/삽입 위치를 분리한 출처 자료.
- 참회 제1·2·3양식: 각 원문 지시문·침묵·고백/호칭·사죄 위치에 연결. 제3양식은 자비송 포함 상태 유지.
- 감사 기도 제2양식: 99–106항의 팔·손·예물 위 십자·성찬 제정·성체/성작 거양·깊은 절·마침 영광송 지시 연결.
- 경본의 `아무` 자리표시자를 유지. 기존 사진의 실명과 종을 치면 함께 절한다는 앱 안내는 경본 원문으로 취급하지 않음.
- 두 신경의 깊은 절 지시문과 해당 구절을 유지. 신앙 고백 제목 도움말은 경본18–19항의 양식 안내로 교체.
- 독서·화답송·복음 환호송·강론·예물 기도·영성체 성가·영성체 후 기도·공지·파견에 원본 지시 연결.
- 원문 지시문은 `[원문 지침]` 내부 마커, 화면에는 마커 없이 기존 안내 글꼴/색상 사용. `data-source-kind=missal-rubric`, PDF쪽/항 번호를 보관.
- 원문 지시문은 두 사용자 모드에서 유지. 앱 해설의 선택 표시와 구분.
- 사제 동작 지시문은 합송 카드와 분리. 가슴을 치기·신경 중 절 지시는 합송 구절 안에 유지.
- 기존 토큰·레이아웃·저장 키·악보 조판은 변경하지 않음.

## 검증
- `node tools/check-missal-rubrics.cjs`: 두 화면, 두 모드, 전체 전례 블록과 참회 세 양식 렌더링256개 검사 통과. 브라우저 JS 오류0.
- 실제 제2양식 클릭과 페이지 나눔, 감사 기도 제2양식 이동 확인.
- 결과: `work/browser-qa/missal-rubrics.json`, `missal-form2.png`, `missal-eucharist2.png`.
- CSS/토큰 변경 없음. 기존 안내·카드 컴포넌트 재사용. 접근성 전체 재검사나 모든 날짜/테마 조합 검사 완료를 주장하지 않는다.

## 남은 범위
전체 기도문 문장 교감은 미완료. 지시문을 확인한 사실과 기도문 전체 검증을 구분한다. 경본의 감사 기도I·III·IV, 주교/장엄 강복, 기원·화해 감사 기도, 장례 고유 전구 등 새 선택기는 이번에 추가하지 않았다. 원본 PDF와 예전 초안은 보존한다.

## 다음
삽입 위치와 읽기 흐름을 시각 검수한 뒤, 현재 표시 기도문 전체를 항별로 교감하고 날짜별 고유문과 통상문 연결 경계를 확인한다. 7단계 유지, 문의 발송은 출시 준비 때까지 보류.
