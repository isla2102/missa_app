# 8단계 · 날짜별 자료 연결 및 검증 계획

기준: 2026-10-24 사용자 7단계 최종 컨펌. 확정 디자인과 본당 악보를 유지한다.

## 현재 자료 범위
- 실제 연결된 날짜: data/days/2026-10-18.json.
- 제공된 월별 고유문: 2026년 10~12월 HWP. 원본 보관 확인과 본문 날짜 파싱 검증은 별개이며 후자는 아직 필요하다.
- 성가표: 10월 및 11월 자료. 수정본 우선, 추천과 본당 확정 편성 구분.
- 통상문은 공통 기준으로 유지하고 날짜별 고유문과 분리한다. 경본 악보는 참고 보관하며 현재 본당 악보를 교체하지 않는다.

## 진행 순서와 산출물
1. HWP·성가표의 실제 날짜와 항목을 판독하고 날짜별 연결 현황을 작성한다. 자료가 없는 날짜·항목을 명시한다.
2. 출처 파일·원문 위치·확인 상태를 가진 날짜 JSON을 연결한다. 이미 연결된 10월 18일을 기준으로 대표 날짜를 검증한 뒤 확보 범위를 확장한다.
3. 각 연결 날짜에서 본기도·독서·화답송·복음·예물 기도·영성체 후 기도 등의 원문과 표시를 대조한다. 대안·조건부 항목과 끝 응답의 중복·누락을 검사한다.
4. 날짜·회차·신자 모드 전환, 성가 편성, 페이지 이동·목차·저장 복원을 전체 흐름으로 재검증하고 docs/08-qa.md에 증거와 한계를 남긴다.

미확인 자료를 확정 본문으로 표시하지 않고 미연결 상태를 유지한다. 회차별 성가 편성과 날짜별 미사 본문을 혼동하지 않는다. 실제 출시 준비 시 권리 문의를 재안내하며 현 단계에서는 메일을 발송하지 않는다.
