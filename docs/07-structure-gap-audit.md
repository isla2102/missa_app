# 래퍼·형제·화면 카드 구조 검수

## 판정
검토 샘플의 검사 범위에서 위반 0건. 이전 가로 전용 검사로는 부족했고, 세로 전용 display:block 예외를 발견해 제거했다. 시스템 토큰 확정/8단계 구현 완료 판정과는 별개다.

## 구조와 간격 소유권
- 섹션 flow: 제목·본문 래퍼·마침 묶음을 형제로 배치, gap8px. 섹션 간16px.
- 내용 래퍼: 추가 상하 padding/margin0. 본문·선택영역·악보에 맞는 하위 구조를 보유.
- liturgy/dialogue: 직접 형제 발화 카드 gap8px.
- speech-card: 바깥 margin0, 내부 상하8px/좌우12px.
- 안내: 별도 역할로 상하4px. 본문 열 정렬. 무조건 스피치 패딩과 같게 만들지 않음.
- 악보: 추가 상하 padding/margin0, 원본 이미지의 자체 여백 유지.

본문/악보/선택 양식의 DOM 태그를 모두 같게 만들지는 않는다. 동일한 책임의 래퍼와 형제가 동일한 배치·간격 규칙을 소유하도록 정규화했다.

## 측정 범위
2날짜(10/18연결·10/24미연결) × 가로/세로 × 예비신자/일반 × 3테마 × 28전례항목 = 672조합.

| 검수 층 | 규칙 | 측정 횟수 | 위반 |
|---|---|---|---|
| 래퍼 | flex/grid 및 row-gap8 | 9744 | 0 |
| 직접 형제 카드·래퍼 | 수직 경계8px | 3984 | 0 |
| 중첩 래퍼를 넘는 보이는 카드 | 같은 섹션 경계8px | 3984 | 0 |

횟수는 여러 펼침에서 반복 표시된 카드 포함. 서로 다른 섹션의 제목이 끼어 있는 경우는 단순8px 비교 대상이 아니며, 섹션 간16/제목행32/제목-본문8의 규칙으로 구분한다.

## 수정 원인
세로보기의 .reader__book--continuous .reader__item--collect/score/reading/compact-score가 공통 flow를 block으로 덮어썼다. 원래 예외 규칙을 제거해 가로·세로의 동일 책임을 통일. !important나 인라인 스타일 추가 없음.
