# 감사송 연결 및 참조 지시 현황 (8단계)

최신: 2026-10-24 · 8단계 진행 중.

## 1. 개요 및 정책

- **배경**: 미사의 감사송은 전례일·축일·시기에 따라 고유 감사송 전문이 사용되거나, 선택 가능한 공통 감사송(연중 주일 1~8, 대림 1~2, 성탄 1~3, 동정 마리아 등) 중 집전 사제가 선택하여 바칩니다.
- **제공 HWP 원본 특징**:
  - 특정 대축일·축일에는 감사송 전문이 직접 수록되어 있습니다 (총 6일).
  - 대다수 주일 및 기념일에는 `<연중 주일 감사송 가운데 하나를 자유롭게 선택한다.>` 등과 같은 지시문(선택 안내)만 수록되어 있습니다.
  - 일반 평일에는 별도 감사송 지시가 없습니다.
- **앱 렌더링 규칙**:
  1. **전문 수록일 (6일)**: 날짜별 JSON의 `preface` 섹션 전문을 감사기도 제2양식 도입부(`+ ` 뒤)에 직접 결합하여 표시하며, 거룩하시도다 환호 중복을 방지합니다.
  2. **참조 지시일 (`prefaceHints` 존재)**: 원문 지시문을 `[원문 지침]` 라벨로 명시하고, `[선택 날짜 감사송 전문 미연결 · 집전 사제의 선택에 따릅니다.]`를 병기하여 임의의 감사송을 추측 대체하지 않습니다.
  3. **지시 없는 평일**: 감사기도 제2양식의 기본 고유 감사송(`+ 거룩하신 아버지, 전능하시고 영원하신 주 하느님...`)을 그대로 유지합니다.

## 4. 향후 릴리즈 준비 시 고려 사항

- 현재 개인 테스트 단계에서는 임의 조작 없이 원문의 지침과 전문 미연결 상태를 정직하게 표시합니다.
