# 본당 악보 가사·낭송문 대조 — 참고 기록

## 결과
- 현재 앱 registry에 연결된 재조판 SVG11개(9종, 신앙의 신비3응답 포함)를 확인.
- 11개 모두 가사 verse 요소가 해당 MusicXML 가사와 음절 기준 일치. 성가대·합송·템포 등 지시문은 가사에서 제외.
- 낭송문과의 음절 비교: 8개 일치. 3개는 명시한 음악적 반복만 차이.
  - 아멘 악보: 아멘3회 / 낭송1회.
  - 대영광송: 끝의 아멘3회 / 낭송1회.
  - 주님의 기도: 악에서2회 / 낭송1회.
- 나열한 반복을 비교 단계에서만 축약하면11개 모두 일치. 악보 파일이나 앱 낭송문을 반복에 맞춰 변경하지 않았다.
- 알렐루야는 후렴1회에 포함된3번 반복을 앱 낭송 후렴3번과 비교했다. 미사 진행 중 앞뒤 후렴2개와 날짜별 절 구절을 하나의 가사로 섞어 비교하지 않았다.
- 주님의 기도 악보는 합송 본문만 비교. 사제 도입과 후속 기도는 해당 악보 범위에 포함하지 않았다.

## 판정의 한계
띄어쓰기·문장부호·음절 배치·절 번호를 제외한 한글 음절 문자열 대조다. 악보 선율의 적법성이나 경본 선율과 동일성을 판정하지 않는다. 음정·리듬·음표 및 원본 사진 전체의 수작업 교감은 이번 범위 밖이다. 본당 최종 교정 상태도 바꾸지 않았다.
사용자 입력 성가번호의 원격 악보, 미등록 화답송·보편 지향 기도·신경 악보는 대상에서 제외했다. 음악적 반복은 삭제하지 않는다.
