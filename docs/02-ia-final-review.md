# MISSA 2단계 IA 최종 검토 후보 — v72

2026-10-21. 2026-10-21 사용자 IA 최종 승인 완료. 3~8단계 완료를 뜻하지 않는다.

## 화면 동작 결정
- 기본: 태블릿 가로1024×768 두쪽. 보기 설정은 가로→세로→현재화면맞춤. 세로는 한 열 연속스크롤.
- 상단 날짜/전례시기/회차/모드 한줄. 세로에서는 성가/기도문을 메뉴로 접근.
- 네예식 목차/이전다음 이동. 중간 빈쪽 자동삽입 대신 오른쪽에서 길어지는 섹션은 한 스크롤쪽. 섹션 내부 선택버튼은 분할로 복제하지 않음.
- 내부스크롤 최소10rem. 독서/화답송 최소행18/14rem, 공간부족시 바깥쪽스크롤. 독서기호/절번호 왼쪽, 다음표식 전까지 본문은 같은 오른쪽열.
- 긴안내는 제목 우측 안내버튼→모달. Esc/닫기/초점복귀. 본기도 선택은 제목행, 신앙고백 니케아신경/사도신경 같은행.
- 참회1/2/3양식 선택. 제3은 참회에 자비송포함, 자비송항목에는 별도반복하지않는다는 안내. 제1/2의 별도자비송은 낭송/성가.
- 악보는 SVG/이미지모달, 성가번호는 하단우측 작은캡션. PDF브라우저UI 사용하지않음.
- 날짜/회차별 성가 복수번호저장, 추천적용은 명시버튼. JSON백업/검증미리보기/복원/취소, 구버전 번호선별가져오기. 기존가사메모는 구버전저장소보존.

## 구현 완료와 구분할 콘텐츠 미완료
- 제2양식: 버튼과 미연결안내만 존재, 공식본문 미연결.
- 날짜별본문: 현재2026-10-18 연결샘플도 일부연결이며 모든날짜완료아님.
- 주요기도문21종/주보: 원문출처링크 중심. 주보화답송악보 자동연결 미구현.
- 2026년10월성가표31일: 추천이며 본당각회차공식편성확정아님. 다른달데이터 미등록.
- 본당실제미사시간/미확인악보번호/공식전문 추가는 추측하지않음.
- 새전문내장/추가자동수집/배포범위는 권리서면확인전보류. docs/content-source-policy.md 및 data/reference-sources/rights.json 기준. 문의발송없음.
