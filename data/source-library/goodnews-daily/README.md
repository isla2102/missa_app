# 굿뉴스 매일미사 말씀 전례 보관

사용자 요청에 따라 2026-10-01~12-31, 92일의 한국어 기본 미사 페이지에서 말씀 전례를 수집했다.

- html/: 서버 응답 원본. 실행하거나 앱에 HTML로 삽입하지 않는다.
- parsed/: 날짜·전례명·절별 문단·본문 구획·원본 해시·출처 URL.
- manifest.json: 92일 수집 현황.
- link-audit.json: 실제 연결과 본문 대안·별도 보존한 후속 지시.

수집: python tools/collect_goodnews_daily.py (기존 캐시 재사용, 요청 간 대기, 응답 날짜 불일치 시 중단).
연결: python tools/link_goodnews_daily.py.
검사: python tests/test_goodnews_daily.py / node tools/check-goodnews-daily.cjs.

범위는 해당 날짜의 사이트 기본 미사 양식이다. 11월2일은 첫째 미사, 12월25일은 밤 미사로 제공됐다. 모든 특별 미사 양식을 수집했다는 뜻이 아니다. 독서·복음 내 대안8개는 앱의 본문1/본문2로 분리했다. 별도 기념일 독서 가능 등의 후속 메모는 원문/대조 기록에 보관했다.

고유기도문의 축약된 끝구절을 이 사이트에서 추측 보완하지 않는다. 기존 HWP 기도문과 본당 악보는 유지한다. 현재는 개인 테스트이며 정식 출시 준비 시 이용 문의를 재안내한다. 메일은 발송하지 않았다.
