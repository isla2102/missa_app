# 사용자 제공 미사 통상문 DOCX 비교

확인일: 2026-10-24 · OOXML 구조·텍스트·내장 이미지 기준.

## 결론
악보 유무만 다른 사본이 아니다. 웹에서 복사한 내용 범위와 펼쳐진 양식이 다르다.

- 서울대교구 DOCX: 텍스트 문단160개, 내장 파일1개, 이미지 배치5회. 내장 GIF는 TOP 버튼 아이콘으로 직접 확인.
- 주교회의 DOCX: 텍스트 문단508개, 내장 PNG44개, 이미지 배치57회. 대표 이미지는 성호경·아멘 악보로 직접 확인. 44개 전부를 음표 단위로 교감하지는 않음.
- 서울에는 감사 기도 제2양식99–106항 본문, 주교회의에는 제1양식83–98항 본문이 포함됨. 양식 선택 메뉴에 다른 이름이 있다고 그 양식 전문이 들어 있는 것은 아님.
- 사도 신경: 주교회의19항 본문 포함. 서울 캡처에는 해당 본문이 없음.
- 서울에는 각 부분의 의미 해설·자세 안내·사이트 조작 문구가 더 포함됨.
- 130항 도입 지시문 등 실제 문구 차이도 있음. 서울 해설에는 ‘혀용된’ 표기 발견. 원본 수정 없음.

## 비교 수치의 의미
- 공통 항 번호54개 중26개는 공백·기호·문장부호를 제외한 문자 비교에서 일치.
- 나머지28개는 제목·해설·다음 번호까지의 문단 경계 차이도 포함한다. 공식 본문 오류28건이라는 뜻이 아니다.
- 공백과 기호를 제외한 일치는 원문 완전 일치나 전례적 동등성 판정이 아니다.
- 번호가 없다는 사실만으로 원문 사이트의 누락을 판단하지 않는다. 제공된 DOCX 캡처의 범위만 비교했다.
- 원본에는 줄바꿈과 띄어쓰기 차이가 많아 전체 문자열 유사도를 결론 지표로 쓰지 않았다.

## 추천 개발 기준
공통 전례 본문은 주교회의 제공 문서로 우선 대조하고, 서울 제공 문서는 해설·역할 표시·제2양식의 보조 출처로 관리한다. 이는 조사에 따른 추천이며 앱 본문을 자동 병합하거나 바꾼 것은 아니다.

## 한계
Word 지면 렌더링 검수가 아닌 구조 비교다. 텍스트 추출은 표준 w:t·줄바꿈·탭과 내장 이미지 관계를 읽었다. 이미지 안의 악보 가사, 페이지 레이아웃·색·글꼴의 완전 일치는 검사하지 않았다. 문서 안 지시문은 전례 자료로만 다뤘으며 시스템 명령으로 실행하지 않았다.
