# 5단계 · 화면 배치 검토 중

사용자 요청: 기존 두 페이지/오른쪽 목차 유지, 목차 접어서 본문 확대도 확인. 개발 정보는 평소 접기. 바깥 페이지 스크롤 중심.

- 비교 파일: review/05-wireframe-v1.html
- 목차 접기/펼치기, 가로/세로, 본문/악보 전환. 선택 저장 없음.
- 실제 가로1024×768 크기. 접기 전 한 페이지385px, 접기 후481px.
- 회색 Low-fi이며 배치용 예시 문단. 공식 문구·최종 컴포넌트 디자인이 아님.
- 앱의 목차 접기/상단 접기/스크롤 정책 변경은 시안 승인 후 반영. 이번에는 현재 앱의 토큰 구조만 변경.
- 상태: 사용자 시안 검토 대기. 5단계 확정 아님.

## v2 · 가로 섹션 제목 고정
- 사용자 보완 요청 반영. 제1/2독서·화답송 제목은 가로 페이지 스크롤 상단에 sticky. 세로는 기존 흐름 유지.
- review/05-wireframe-v2.html, v1 보존. 기존 앱 배치에는 아직 미적용.

## 5단계 v3 · 제목 상단 틈 수정
- sticky 기준을 페이지 패딩만큼 위로 보정하여 스크롤 영역 상단까지 불투명 제목 배경으로 덮음.
- review/05-wireframe-v3.html, v1/v2 보존. Chrome 두 페이지 × 목차 펼침/접힘에서 제목 상단 틈0, elementFromPoint로 상단 덮임 확인 PASS. PNG 직접 확인.

## 5단계 v4 · 전례 이동과 목차 버튼 정렬
- 다음 전례 버튼은 본문 2페이지 우측 상단, 목차 접기/펼치기는 기존 다음 전례 위치인 목차 상단 우측. 바깥 비교 도구의 중복 목차 버튼 제거.
- Chrome 본문/목차 우측 경계 정렬과 접기·복원·폭 확대 PASS. review/05-wireframe-v4.html. v1~v3 보존.
