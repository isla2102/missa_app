# 7단계 최종 사용 흐름 검수

2026-10-24 · 자동 조작 검수 완료 / 사용자 최종 시각 확인 대기. 8단계 미진입.

## 검증
- Windows Chrome 독립 브라우저 컨텍스트에서 실제 click·입력·선택·Escape·reload 조작. 사용자 실제 브라우저 저장소는 변경하지 않음.
- 1024×768 가로, 앱의768×1024 세로 미리보기. 실제 태블릿 터치나 브라우저 주소창 높이는 재현하지 않음.
- 30항목 PASS, 전체 미사15회 페이지 이동으로 네 전례 도달, 빈 펼침0, 브라우저 JS오류0.
- 목차 이동·축소/복원·큰 꼭지4개, 모드/회차 변경 시 읽기 앵커 유지.
- 새로고침 후 날짜·모드·회차·읽던 앵커·테마·본문 글꼴 복원.
- 미연결 날짜의 자료 상태와 독서 영역 미연결 표시, 날짜를 되돌렸을 때 해당 날짜 위치 복원.
- 검수 브라우저에서 입당 성가23번을 입력해 회차별 분리와 새로고침 복원 확인. 실제 사용자 편성이나 기본 성가 번호를 지정한 것이 아님.
- 설정 Escape 닫기와 포커스 복원, 신앙 고백 안내창 열기/닫기, 악보 크게 보기 열기/닫기, 확대창에 불필요한 확대 버튼 없음 확인.
- 세로/가로 미리보기 전환 및 세로 상단 로고/날짜 겹침 해소 확인.

## 발견·수정
- 세로 미리보기의 상단3열 grid에서 로고·날짜가 겹침. 같은 grid를 두 행으로 배치: 첫 행 로고/메뉴, 둘째 행 날짜/회차/모드. 새 색·간격·글자 토큰 추가 없음.
- 안내에 남은 ‘선택 체크’와 ‘강조 테두리 카드’ 설명을 현재 와인 면·굵기 표현으로 정정.
- 미연결 날짜의 시작 예식에도 공통 통상문은 정상 표시된다. 검사 기준은 고유문 영역과 자료 상태로 보정. 이를 앱 결함으로 집계하지 않음.
