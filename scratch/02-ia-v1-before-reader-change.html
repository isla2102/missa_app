미사에 집중하는 화면 구성

정보 구조와 이동 경로를 검토합니다. 색·폰트·최종 레이아웃은 이후 단계에서 정합니다. 전례문·실제 성가·시간표는 포함하지 않았습니다.

구조 비교A안 동선 체험검토 기준승인할 내용

보조 기능에 접근하는 두 가지 경로

공통 결정: 내 본당 하나 · 상단 날짜/회차/모드 · 연속 본문 두 페이지 · 오른쪽 오버레이 Drawer.

A안 · 기능 바로 열기 (추천)

리더 → 목차 / 성가 / 기도 / 보기 설정 / 안내 → 해당 Drawer.

  • 성가와 기도에 한 번에 접근합니다.
  • 개발용 예시는 안내 안으로 분리합니다.
  • 항목이 늘면 탐색 항목의 정리가 필요합니다.

미사 중 빠르게 열고 본문으로 돌아가는 개인용 MVP에 적합합니다.

B안 · 하나의 메뉴에서 찾기

리더 → 보조 메뉴 → 목차 / 성가 / 기도 / 보기 설정 / 안내.

  • 리더의 탐색 진입점이 하나입니다.
  • 각 기능을 열기까지 한 단계 더 필요합니다.
  • 추가 기능을 메뉴 아래에 모으기 쉽습니다.

후속 확장에는 유리하지만 현재 다섯 기능을 열 때 이동이 늘어납니다.

A안 동선 체험

회차와 모드를 바꿔도 아래 공통 문서와 현재 펼침은 유지됩니다. 이 체험에는 성가 편집·전례 엔진·로컬 설정 저장 기능이 없습니다.

내 본당 · 실제 이름 미설정 · 시간 미확인

공통 문서: 주일 순서 구조 예시 · 공식 전례력 미연동

검토 기준과 예외 처리 제안

  • 회차별로 전례일·본문·순서·안내 규칙은 동일. 입당·봉헌·영성체·파견 성가만 분리합니다.
  • 본문의 좌우는 연속된 두 쪽입니다. 작은 화면에서는 둘 다 세로로 보여 누락하지 않습니다.
  • Drawer는 본문 위에 열고, 닫을 때 원래 버튼으로 키보드 초점을 돌립니다. Escape로 닫을 수 있습니다.
  • 제안: 평일 개발 예시에서는 주일 회차 편집을 비활성화하고 ‘회차 미적용’으로 표시합니다. 선택한 주일 회차는 기억합니다. 다시 주일 예시로 돌아오면 복원하며 날짜는 자동 변경하지 않습니다.
  • 날짜 선택 시 미연동 상태를 표시합니다. 자동 판별이 구현되기 전에는 선택 날짜의 공식 전례라고 주장하지 않습니다.

사전 점검: 의미론적 제목·입력 레이블·키보드 초점·기본 44px 상당 조작 영역을 고려했습니다. 디자인 시스템 대조는 4단계 이후 대상이며, 전체 접근성 적합 판정은 아직 수행하지 않았습니다.

승인할 내용

A안의 직접 접근 구조와 평일 개발 예시의 ‘회차 미적용’ 정책을 추천합니다. 검토 후 채팅에서 ‘A안 승인’ 또는 수정할 부분을 알려 주세요. 화면 조작은 승인으로 저장되지 않습니다.
