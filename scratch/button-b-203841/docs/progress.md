## 실제 원본 점검 결과
- 회차와 무관하게 pageData()가 같은 samples/scenarios로 전례 순서를 생성함. 이 공통 구조는 유지 대상.
- 회차 목록에 임의 시간(06:00, 11:00, 19:00 등)과 가상 방문 본당 편성이 있음. 사용자 요구에 따라 제거 또는 미확인 처리 필요.
- 젊은이 미사 표기는 '저녁 청년미사'로 일요일이 명시되지 않음. 토요일 표기는 발견되지 않음.
- massInstance 예시에 localStart 19:00, usesVigilTexts, celebrationOverride가 있음. 공통 MassDocument 참조와 회차별 HymnSet으로 제약 필요.
- 회차 변경은 spread를 초기화하지 않지만 render()가 본문 DOM 전체를 교체함. 안정적인 문단 식별자/offset 복원 없음.
- 로컬 저장은 성가에만 적용됨. 모드·글자 크기·다크·읽던 위치 저장 및 북마크 없음.
- 성가 Drawer가 열려 있을 때 회차 변경 시 setPanel('hymn')가 패널을 닫는 동작임.
- 영성체 항목에 kind: hymn이 없어 본문에서 영성체 성가 편집 링크가 나타나지 않음.
- 키보드 전역 처리에서 textarea를 제외하지 않아 가사/메모 편집 중 화살표로 페이지 이동 가능.
- 모바일은 두 번째 페이지를 숨기면서 두 페이지씩 이동하여 본문 일부 접근 불가.
- 공식 콘텐츠 연결 및 자동 조판은 미구현. 표시 본문은 안내용 자리표시자이며 공식 전례문이 아님.
- CSS 토큰/레이어/반응형 분리 및 접근성은 이후 해당 단계에서 검수 필요. 자동 검사 통과를 주장하지 않음.
