# System Design & Architecture
## Core Conventions
1. 하드코딩을 금지한다.
2. 기존 파일을 무단 덮어쓰지 않는다.
3. 웹디자인 확정 사항은 단계별 docs 파일, DESIGN.md와 styles/tokens.css를 단일 출처로 관리한다.

## 설계 문서 위치
제품 결정은 루트 design.md, 진행·승인 이력은 docs/progress.md가 기준이다. 이 파일은 공통 규칙과 문서 안내만 유지한다. Windows의 design.md와 DESIGN.md는 같은 파일이므로 4단계 디자인 시스템을 루트 문서에 누적한다.
